# Compliance (SOC 2–ready)

This directory holds **markdown control narratives** and lightweight policies so evidence collection is straightforward if you pursue a SOC 2 attestation later. It is not a substitute for an auditor engagement.

- `controls/` — control descriptions mapped loosely to Trust Services Criteria themes.
- `policies/` — organizational policies (placeholders to refine with counsel).
- `evidence/` — reserved for automation outputs (screenshots, scan exports); keep sensitive data out of git.

See individual files for scope and owner responsibilities.
